Sidebar

The navigation bar on the left, with header, items, sub-items, account and utilities at the bottom. Slide-in on small screens, compact (icons only) on large ones.

Structure

The sidebar sits inside .kit-app, next to .kit-app-main: on the left the full-height bar, on the right the column with the header (.kit-header) and the content (.kit-main). The bar has three parts: kit-sidebar-head (logo), kit-sidebar-body (the items, scrolls by itself if there are many) and kit-sidebar-foot (account and utilities, always at the bottom).

Overview

The page content.

  • Each item is kit-side-link on an <a> or a <button>: icon, then the text inside <span class="kit-side-text"> (needed, because it disappears in the compact version), then an optional badge.
  • The current page is marked with aria-current="page" (or is-active); an unavailable item with aria-disabled="true".
  • kit-side-title is the title of a group of items; in the compact version it becomes a separator line.
  • Give the <aside> an id and an aria-label.

Together with the header

The header is the usual one (kit-header), but it sits inside kit-app-main, above the content. The button that opens the sidebar lives there: data-kit-sidebar-toggle with, if needed, the bar's selector. The logo sits at the top of the sidebar, with the same height as the header (--kit-hh), so the two separator lines meet.

<div class="kit-app kit-app-expand-lg">
  <aside class="kit-sidebar" id="sidebar" aria-label="Main"> … </aside>
  <div class="kit-app-main">
    <header class="kit-header">
      <button class="kit-btn kit-btn-ghost kit-btn-icon" data-kit-sidebar-toggle="#sidebar"
              aria-controls="sidebar" aria-expanded="false" aria-label="Side menu">
        <svg class="kit-icon"><use href="#i-menu"/></svg>
      </button>
      …
    </header>
    <main class="kit-main"> … </main>
  </div>
</div>

nonenever: it is always slide-in

Below that point the sidebar leaves the flow and sits off screen; the data-kit-sidebar-toggle button slides it in from the left, with the background darkening. It behaves like a dialog: the rest of the page cannot be reached (inert), focus moves to the bar, and it closes with Esc, with a click on the background or by choosing a link, returning focus to the button. If the window widens past the breakpoint, the "open" state is reset.

Compact, icons only

On large screens the same button compresses the bar into a column of icons (--kit-side-wc wide) and expands it again. The choice is <html data-kit-sidebar="collapsed|expanded"> and is remembered, like theme and text size. To start compact just write the attribute in the HTML.

  • Texts, badges, arrows and sub-items disappear. Hovering the mouse or moving focus with Tab onto an icon, its name appears right next to it (with the badge number, for example "Alerts (3)"); this applies to items, utilities and the account. The name is taken from the item's kit-side-text or, for icon buttons, from their aria-label. Each item also gets an aria-label by itself, because the hidden text does not reach screen readers.
  • Pressing an item with sub-items expands it again.
  • Kit.reset() and the data-kit-reset button restore the state written in the HTML.

Items with sub-items

An item with a submenu is a <details class="kit-side-details"> with <summary class="kit-side-link">: it works without JavaScript and with the keyboard. The arrow is kit-side-chev; the sub-items are a second kit-side-nav kit-side-sub.

Account and utilities at the bottom

In kit-sidebar-foot go the utilities (kit-side-tools: icon buttons, settings, help) and the account. The account is kit-side-user with kit-side-avatar (the initials) and kit-side-user-text (name and secondary line); its menu is a normal pop-up menu opened upwards with kit-pop-up.

<div class="kit-sidebar-foot">
  <div class="kit-dropdown">
    <button class="kit-side-user" data-kit-toggle="#account" aria-haspopup="menu" aria-expanded="false">
      <span class="kit-side-avatar" aria-hidden="true">MR</span>
      <span class="kit-side-user-text"><b>Maria Smith</b><small>maria@example.com</small></span>
    </button>
    <div class="kit-pop kit-pop-up" id="account" role="menu" hidden>
      <a class="kit-opt" role="menuitem" href="#">Profile</a>
      <button class="kit-opt kit-opt-danger" role="menuitem">Sign out</button>
    </div>
  </div>
</div>

JavaScript

WhatEffect
data-kit-sidebar-toggle="#id"Button: opens or closes the slide-in sidebar, or compresses or expands the inline one. Without a value it acts on the first .kit-sidebar. aria-expanded updates by itself.
Kit.sidebar.get() · set("collapsed|expanded") · toggle()The compact state, remembered.
Kit.sidebar.open(selector) · close(selector)The slide-in sidebar; they do nothing if it is inline.
kit:sidebar eventOn the sidebar (bubbles): detail is { collapsed, open }.

Tokens and print

  • --kit-side-w (16.5rem): width of the bar; --kit-side-wc (4.667rem): width of the compact one. They can be overridden on :root or on a single .kit-app.
  • When printing the sidebar disappears, like the header.
