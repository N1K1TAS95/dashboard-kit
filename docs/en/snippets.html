VS Code snippets

Type the prefix and press Tab: the editor writes the component's markup, with the fields to fill in.

Installation

  • One project only: copy vscode/dashboard-kit.code-snippets into the project's .vscode/ folder.
  • All projects: in VS Code open Preferences: Configure Snippets → New Global Snippets file and paste the file's content.

Then, in an .html file, type for example kit-card and press Tab. With kit-page you get a whole page; with kit-dash the layout of a dashboard (KPIs, chart with side panel, table).
