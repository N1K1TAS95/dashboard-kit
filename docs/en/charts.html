Charts

Bars, lines, donut and sparklines in SVG, no libraries. They require kit.js.

Bar chart

Kit.barChart(element, options) draws a bar chart in SVG inside the element. The vertical axis has round values (1, 2, 2.5, 5, 10 for a power of ten) with thousands abbreviated as "k" and "M". Each bar has a tooltip. If there are many bars the chart scrolls horizontally and starts from the end, that is, from the most recent data. Colors, texts and grid follow the theme and the text size; the chart redraws itself when the window changes width.

Each element of data has a label (label), a value for each series (values) and, optionally, a group: it is written under the bar only when it changes, and is handy for the year.

Several series and clicks

With several series (series) each month has one bar per series and the legend appears. The default colors are --kit-c1…--kit-c4; for another color there is color in the series. With onSelect the bars become buttons reachable with Tab, activated with Enter or space; the element also receives the kit:select event with { index, series, item }.

Stacked bars

stacked: true puts the series one on top of the other: each month has a single bar, as tall as the sum. Useful to see how a total is made up.

Lines

Kit.lineChart takes the same options as bars. A null value leaves a gap in the line (the month without data). The axis starts from the lowest value, not from zero, so variations are visible; zero: true brings it back to zero. Each series has a different symbol (circle, square, triangle), so they can be told apart even without the colors. area: true colors the space under the line, markers: false removes the points.

Donut

Kit.donut shows the parts of a total. In the center is the total (or the text of centerValue and centerLabel), beside it a legend with value and percentage. With onSelect the legend rows become buttons. Slices with a value of zero do not appear.

Chart legend

The series colors are the --kit-c1 and --kit-c2 tokens, which change by themselves between light and dark theme. In SVG charts use them with fill: var(--kit-c1) (see the sample dashboard).

Sparkline

Kit.sparkline is a tiny chart, with no axes, to put next to a number, for example in a KPI card. It takes values and, optionally, type ("line" or "bar"), color, area (false removes it) and label. The size is that of the element: change it with CSS (by default 6rem × 1.9rem).

The function returns { update(options), destroy() }. Calling it again on the same element updates the existing chart: Kit.barChart(el, { data: newData }) changes only the data. Negative values are not supported in bars (they are drawn as zero). All four functions (barChart, lineChart, donut, sparkline) work this way and return { update, destroy }.

The kit-chart class is added by itself. For the rest the tokens are used: --kit-c1…--kit-c4 for the series, --kit-line for the grid and --kit-mute for the labels. The kit-chart-bar, kit-chart-axis, kit-chart-label and kit-chart-group classes let you touch up the single parts.
