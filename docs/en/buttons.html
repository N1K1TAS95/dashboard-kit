Buttons

Buttons of all kinds and sizes. A .kit-btn works on <button>, <a> and <label>.

Variants

kit-btn-primary for the screen's main action (only one per area), kit-btn-ghost for secondary actions without a border, kit-btn-danger for destructive ones.

Sizes

The base height is --kit-ctl (40px), the same as fields, so buttons and inputs line up. kit-btn-lg brings it to 48px.

With an icon

Put the <svg class="kit-icon"> before the text. For icon-only buttons add kit-btn-icon (square) and an aria-label.
