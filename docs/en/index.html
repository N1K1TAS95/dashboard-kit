Introduction

Dashboard Kit is a small CSS framework, with optional JavaScript, for building dashboards. A single file, no dependencies, light and dark themes, and a 12-column grid like Bootstrap.

Installation

From a CDN (jsDelivr), with the version pinned and the integrity attribute (SRI): if the file were tampered with, the browser rejects it.

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/N1K1TAS95/dashboard-kit@v0.10.0/dist/kit.css"
      integrity="sha384-znCaG7h9kJLl62DAiNyMb9OH8yUsmerFcqlRH1huU4THVZIEyiT8s07zyKW3j/bK"
      crossorigin="anonymous">

<!-- optional: theme, select, tabs, dialog, menus, toasts -->
<script src="https://cdn.jsdelivr.net/gh/N1K1TAS95/dashboard-kit@v0.10.0/dist/kit.js"
        integrity="sha384-dQ6RqrVbs6Kazmd+St8NrRXdUQVsrqThJfMmnfZsbiTk7FHoqOtvdeItwIwymvd6"
        crossorigin="anonymous"></script>

Or locally: copy dist/kit.css (and dist/kit.js) into your project and link them with a relative path.

If your site has a Content-Security-Policy, allow https://cdn.jsdelivr.net in style-src and script-src. Avoid @main or @latest: they are not pinned versions and jsDelivr caches them for hours.

The texts kit.js writes by itself (button labels, "No results", the calendar…) follow <html lang>: English if missing, Italian with lang="it". See Languages.

Page template

The minimal skeleton with a fixed header and a grid for the content. In the editor you get it by typing kit-page + Tab (see VS Code snippets).

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My dashboard</title>
  <script src="dist/kit.js"></script>
  <link rel="stylesheet" href="dist/kit.css">
</head>
<body>
<header class="kit-header">
  <h1 class="kit-brand">Name <span>app</span></h1>
</header>
<main class="kit-main">
  <div class="kit-container">
    <div class="kit-row">
      <div class="kit-col-12 kit-col-lg-8"><section class="kit-card kit-card-body">…</section></div>
      <div class="kit-col-12 kit-col-lg-4"><section class="kit-card kit-card-body">…</section></div>
    </div>
  </div>
</main>
</body>
</html>

Icons

The kit does not include icons: .kit-icon only gives an <svg> its size and stroke. You use an inline sprite in the page and call it with <use>, so the icons take the text color.

<svg width="0" height="0" style="position:absolute" aria-hidden="true" focusable="false"><defs>
  <symbol id="i-search" viewBox="0 0 24 24"><circle cx="11" cy="11" r="7"/><path d="m20 20-3.5-3.5"/></symbol>
</defs></svg>

<button class="kit-btn"><svg class="kit-icon"><use href="#i-search"/></svg>Search</button>

Supported browsers

The light/dark colors use light-dark(), so you need Chrome/Edge 123+, Safari 17.5+ or Firefox 120+. The rest (flexbox, grid, color-mix(), :has() only in the documentation pages) is supported by those same versions.

If you know Bootstrap

The grid, the utilities and the names follow Bootstrap, with the kit- prefix. The differences to keep in mind:

BootstrapDashboard KitNote
.row, .col-md-6.kit-row, .kit-col-md-6Identical, but with default gutters equal to --kit-sp (they tighten on phones).
.btn btn-primary.kit-btn kit-btn-primaryVariants are separate classes, not double-dash modifiers.
.d-flex, .mt-3.kit-d-flex, .kit-mt-3Spacing scale 0–5 in px: 0, 4, 8, 16, 24, 48.
.modal, .dropdown<dialog class="kit-dialog">, .kit-dropdownThe dialog is the browser's native element.
Theme with data-bs-themedata-theme on <html>Automatic by default, can be forced to light or dark.
xxl breakpoint—Not present: add it in tools/gen-grid.py.
