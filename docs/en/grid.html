Grid

A 12-column flexbox grid, with the same names as Bootstrap. It is built with rows and columns and changes as the screen width changes.

How it works

  • A .kit-row contains .kit-col-* columns; each row has 12 columns and wraps by itself.
  • It is mobile first: a class without a breakpoint applies everywhere, kit-col-md-6 applies from 768px up.
  • The row has negative margins that compensate the columns' padding (the gutters): put it inside a container with padding, like .kit-main or .kit-card-body.
  • The row's direct children are all columns: even a <div> without a class is 100% wide.

Cards of equal height

The columns of a row already have the same height, but the card inside does not. Add kit-h-100 to the card.

Alternative: CSS Grid

When you do not need per-column breakpoints, kit-grid fills the row with as many columns as fit (at least 240px each). kit-grid-2 and kit-grid-3 fix 2 or 3 columns (just one below 900px).
