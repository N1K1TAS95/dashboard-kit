Themes and tokens

The whole look comes from a few CSS variables. Changing them in :root, or on a single element, changes colors, density and corners of the whole interface.

Light and dark theme

Colors are written once with light-dark(light, dark). By default the theme follows the system; to force it set data-theme on <html>. With kit.js buttons with data-kit-theme-set are enough (the choice is remembered); the same goes for the settings panel, which gathers them with text and width.

<html lang="en" data-theme="dark">           <!-- forced dark; without the attribute it follows the system -->

<button class="kit-btn" data-kit-theme-set="light">Light</button>
<button class="kit-btn" data-kit-theme-set="dark">Dark</button>
<button class="kit-btn" data-kit-theme-set="auto">Automatic</button>

Theme selector (menu)

The header's "Theme" menu is a pop-up menu (.kit-pop) whose items have data-kit-theme-set: on click kit.js applies the theme, remembers it and closes the menu. Each item has an icon and a title, and can have a gray line; kit-pop-right aligns the panel to the right edge, useful in a header. This example is really wired to the page's theme.

Font and text size

The kit uses Inter (OFL license, 65 KB, file dist/fonts/inter-var.woff2), designed for the screen and with a slashed zero that is not confused with the letter "o". The file sits next to kit.css and loads by itself; if it is not reachable the system font remains. To use another font just change --kit-font; for the slashed digit alone, font-variant-numeric: slashed-zero works with any font that provides it.

:root { --kit-font: "IBM Plex Sans", system-ui, sans-serif; }   /* another font */
td.code { font-variant-numeric: slashed-zero tabular-nums; }  /* slashed zero and equal-width digits */

All text sizes are in rem, so they follow the base size --kit-fs (1rem). The base grows by itself with the screen: 15px up to 1279px, then 16px, 17px (from 1600px), 19px (from 1920px) and 22px (from 2560px). Control height, icons, header and content width are also in rem and grow along with the text.

The user can enlarge or shrink everything: --kit-zoom multiplies the base and data-kit-fs on <html> sets it (md normal, the default; lg large; xl extra large). With kit.js buttons with data-kit-fs-set or data-kit-fs-step are enough; the choice is remembered. These choices are also in the settings panel.

<button class="kit-btn" data-kit-fs-step="-1" aria-label="Smaller text">A−</button>
<button class="kit-btn" data-kit-fs-step="1"  aria-label="Larger text">A+</button>

<button class="kit-btn" data-kit-fs-set="xl">Extra large</button>
:root { --kit-fs: 16px; }                                   /* fixed base, no automatic growth */
@media (min-width: 2000px) { :root { --kit-fs: 24px; } }   /* or a threshold of your own */

Scrollbars

All scrollbars (page, tables, menus, dialogs) are thin, with the thumb in the secondary text color and an invisible track. The color is the --kit-sb token, which follows the light and dark theme by itself. The kit-no-scrollbar class hides the scrollbar of an element that still scrolls (useful for a row of tabs on narrow screens).

Customizing

Override the tokens in :root after loading kit.css:

:root {
  --kit-accent: light-dark(#0f766e, #5eead4);
  --kit-accent-soft: light-dark(#e6f6f4, #12312e);
  --kit-rad: 6px;      /* less rounded surfaces */
  --kit-rad-sm: 4px;   /* less rounded controls */
  --kit-row: 5px;      /* more compact tables */
  --kit-ctl: 36px;     /* shorter buttons and fields */
}
