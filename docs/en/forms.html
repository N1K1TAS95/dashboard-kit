Forms: basic fields

Text field, search, checkbox and switch. Buttons and fields have the same height (--kit-ctl), so they sit well on the same row.

Fields

.kit-field is the label with the field below it; .kit-input applies to <input>. .kit-fields lays out several fields in a grid that adapts.

The rest of the forms is on these pages: Layout and validation (labels, help text, column, grid and horizontal forms, valid and invalid states with error messages, validation, sizes, icons inside fields, selectable groups and cards), Select and file (custom select, file field, drop zone, combobox) and Dates and times (optional calendar, designed for the phone too).

Search

A field with a magnifier and a keyboard shortcut. It stretches to fill the row (flex: 1).

Checkbox and form footer

Switch

An on/off that takes effect immediately, unlike a checkbox that is confirmed with a button. It is a normal <input type="checkbox"> with role="switch": checked, disabled and the change event work as usual. kit-switch-between puts the text on the left and the switch at the far right.
