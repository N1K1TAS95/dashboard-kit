Utilities

One-line classes, as in Bootstrap: spacing, display, flexbox, sizes, text and visibility. Almost all use !important to win over components.

Margins and padding

Format kit-{m|p}{side}-{n}. Sides: none (all), t top, b bottom, s start, e end, x horizontal, y vertical. The n scale goes from 0 to 5; margins also have auto.

Display

kit-d-{value} with value none, inline, block, inline-block, flex, inline-flex, grid. With a breakpoint it applies from there up: kit-d-md-none.

Visible from md (768px) up: kit-d-none kit-d-md-block
Visible only below md: kit-d-md-none

Resize the window to see the two boxes alternate.

Flexbox

With kit-d-flex you enable direction (kit-flex-row, -column, -row-reverse, -column-reverse), wrapping (kit-flex-wrap, -nowrap), kit-justify-content-{start|end|center|between|around|evenly}, kit-align-items-{start|end|center|baseline|stretch}, kit-align-self-*, kit-flex-grow-1, kit-flex-shrink-0, kit-flex-fill and kit-gap-0…5. Direction, justify and align also have a per-breakpoint version.

Sizes

kit-w-100, kit-w-auto, kit-h-100, kit-h-auto. kit-h-100 is often needed to make a card reach the height of the column that contains it.

Text and color

kit-mute kit-accent kit-success kit-warning kit-danger 1,234.50 (kit-num: aligned digits)
kit-truncate cuts with an ellipsis a text that is too long for the available space

Others: kit-nowrap, kit-center, kit-right. Size, weight, line height, case and line width are in Typography.

Visibility

  • kit-hidden and the hidden attribute: hide the element.
  • kit-sr: hides it visually but it stays readable by screen readers (labels for icon-only controls).
  • kit-hide-sm (below 760px) and kit-only-sm (only below 760px): shortcuts tied to the phone breakpoint. For the other breakpoints use kit-d-*.

Print

The kit prepares the page for printing: always on light (even if it is dark on screen), without header, alerts and tabs, without shadows, with the page margins reset. Badge and chart colors are kept. Cards, lists, KPI cards and table rows do not split between two pages, and the table header repeats on every page.

  • kit-no-print: the element is not printed (buttons, filters, toolbars).
  • kit-print-only: the element is only visible when printing (document title, date, notes).
  • kit-print-break: goes to a new page; kit-print-avoid: does not split between two pages.

The sheet size and margins are left to the app: @page { size: A4; margin: 14mm } in your CSS.
