Temi e token

Tutto l'aspetto passa da poche variabili CSS. Cambiandole in :root, o su un singolo elemento, si cambiano colori, densità e angoli di tutta l'interfaccia.

Tema chiaro e scuro

I colori sono scritti una volta sola con light-dark(chiaro, scuro). Di base il tema segue il sistema; per forzarlo imposta data-theme su <html>. Con kit.js bastano i bottoni con data-kit-theme-set (la scelta viene ricordata); lo stesso vale per il pannello delle impostazioni, che li riunisce con testo e larghezza.

<html lang="it" data-theme="dark">           <!-- forzato scuro; senza l'attributo segue il sistema -->

<button class="kit-btn" data-kit-theme-set="light">Chiaro</button>
<button class="kit-btn" data-kit-theme-set="dark">Scuro</button>
<button class="kit-btn" data-kit-theme-set="auto">Automatico</button>

Selettore del tema (menu)

Il menu "Tema" dell'intestazione è un menu a comparsa (.kit-pop) le cui voci hanno data-kit-theme-set: al click kit.js applica il tema, lo ricorda e chiude il menu. Ogni voce ha un'icona e un titolo, e può avere una riga in grigio; kit-pop-right allinea il pannello al bordo destro, utile in un'intestazione. Questo esempio è collegato davvero al tema della pagina.

Aggiungi <meta name="color-scheme" content="light dark"> nel <head> per evitare un lampo bianco al caricamento in tema scuro.

Font e dimensione del testo

Il kit usa Inter (licenza OFL, 65 KB, file dist/fonts/inter-var.woff2), pensato per lo schermo e con uno zero barrato che non si confonde con la lettera "o". Il file sta accanto a kit.css e si carica da solo; se non è raggiungibile resta il font di sistema. Per usare un altro font basta cambiare --kit-font; per la sola cifra con la barra, font-variant-numeric: slashed-zero funziona con qualsiasi font che la preveda.

:root { --kit-font: "IBM Plex Sans", system-ui, sans-serif; }   /* un altro font */
td.codice { font-variant-numeric: slashed-zero tabular-nums; }  /* zero barrato e cifre di uguale larghezza */

Tutte le dimensioni del testo sono in rem, quindi seguono la dimensione di base --kit-fs (1rem). La base cresce da sola con lo schermo: 15px fino a 1279px, poi 16px, 17px (da 1600px), 19px (da 1920px) e 22px (da 2560px). Anche altezza dei controlli, icone, intestazione e larghezza del contenuto sono in rem e crescono insieme al testo.

L'utente può ingrandire o rimpicciolire tutto: --kit-zoom moltiplica la base e data-kit-fs su <html> lo imposta (sm 87,5%, md 100%, lg 112,5%, xl 125%). Con kit.js bastano i bottoni con data-kit-fs-set o data-kit-fs-step; la scelta viene ricordata. Anche queste scelte stanno nel pannello delle impostazioni.

<button class="kit-btn" data-kit-fs-step="-1" aria-label="Testo più piccolo">A−</button>
<button class="kit-btn" data-kit-fs-step="1"  aria-label="Testo più grande">A+</button>

<button class="kit-btn" data-kit-fs-set="xl">Molto grande</button>
:root { --kit-fs: 16px; }                                   /* base fissa, senza crescita automatica */
@media (min-width: 2000px) { :root { --kit-fs: 24px; } }   /* o una soglia tutta tua */

Barre di scorrimento

Tutte le barre di scorrimento (pagina, tabelle, menu, dialog) sono sottili, con il cursore nel colore del testo secondario e la guida invisibile. Il colore è il token --kit-sb, che segue il tema chiaro e scuro da solo. La classe kit-no-scrollbar nasconde la barra di un elemento che scorre ancora (utile per una riga di tab su schermi stretti).

Personalizzare

Sovrascrivi i token in :root dopo aver caricato kit.css:

:root {
  --kit-accent: light-dark(#0f766e, #5eead4);
  --kit-accent-soft: light-dark(#e6f6f4, #12312e);
  --kit-rad: 6px;      /* superfici meno arrotondate */
  --kit-rad-sm: 4px;   /* controlli meno arrotondati */
  --kit-row: 5px;      /* tabelle più compatte */
  --kit-ctl: 36px;     /* bottoni e campi più bassi */
}
