Introduzione

Dashboard Kit è un piccolo framework CSS, con JavaScript opzionale, per costruire dashboard. Un solo file, nessuna dipendenza, tema chiaro e scuro, griglia a 12 colonne come Bootstrap.

Installazione

Da CDN (jsDelivr), con la versione fissata e l'attributo integrity (SRI): se il file venisse alterato, il browser lo rifiuta.

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/N1K1TAS95/dashboard-kit@v0.2.0/dist/kit.css"
      integrity="sha384-ZE4JnQC67qFvGRwr7y4q3uvLX1y9Qwq/aXnKJjBx70BzdpcysczD8itvTA6ZRaiv"
      crossorigin="anonymous">

<!-- opzionale: tema, select, tab, dialog, menu, toast -->
<script src="https://cdn.jsdelivr.net/gh/N1K1TAS95/dashboard-kit@v0.2.0/dist/kit.js"
        integrity="sha384-AEH4P4R0t4dzaw+5VjI1pgZSgW/Wj/2u3MoiA/Mf79mCaw89ElUxuUETBSKFSAJM"
        crossorigin="anonymous"></script>

Oppure in locale: copia dist/kit.css (e dist/kit.js) nel progetto e collegali con un percorso relativo.

Se il sito ha una Content-Security-Policy, autorizza https://cdn.jsdelivr.net in style-src e script-src. Evita @main o @latest: non sono versioni fissate e jsDelivr le tiene in cache per ore.

Modello di pagina

Lo scheletro minimo con intestazione fissa e contenuto in griglia. Nell'editor lo ottieni scrivendo kit-page + Tab (vedi Snippet VS Code).

<!doctype html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>La mia dashboard</title>
  <script src="dist/kit.js"></script>
  <link rel="stylesheet" href="dist/kit.css">
</head>
<body>
<header class="kit-header">
  <h1 class="kit-brand">Nome <span>app</span></h1>
</header>
<main class="kit-main">
  <div class="kit-container">
    <div class="kit-row">
      <div class="kit-col-12 kit-col-lg-8"><section class="kit-card kit-card-body">…</section></div>
      <div class="kit-col-12 kit-col-lg-4"><section class="kit-card kit-card-body">…</section></div>
    </div>
  </div>
</main>
</body>
</html>

Icone

Il kit non include icone: .kit-icon dà solo dimensione e tratto a un <svg>. Si usa uno sprite inline nella pagina e lo si richiama con <use>, così le icone prendono il colore del testo.

<svg width="0" height="0" style="position:absolute" aria-hidden="true" focusable="false"><defs>
  <symbol id="i-search" viewBox="0 0 24 24"><circle cx="11" cy="11" r="7"/><path d="m20 20-3.5-3.5"/></symbol>
</defs></svg>

<button class="kit-btn"><svg class="kit-icon"><use href="#i-search"/></svg>Cerca</button>

Browser supportati

I colori chiaro/scuro usano light-dark(), quindi servono Chrome/Edge 123+, Safari 17.5+ o Firefox 120+. Il resto (flexbox, grid, color-mix(), :has() nelle sole pagine di documentazione) è supportato da quelle stesse versioni.

Se conosci Bootstrap

La griglia, le utility e i nomi seguono Bootstrap, con il prefisso kit-. Le differenze da tenere a mente:

BootstrapDashboard KitNota
.row, .col-md-6.kit-row, .kit-col-md-6Identici, ma con gutter di base uguali a --kit-sp (si stringono sul telefono).
.btn btn-primary.kit-btn kit-btn-primaryLe varianti sono classi separate, non modificatori con doppio trattino.
.d-flex, .mt-3.kit-d-flex, .kit-mt-3Scala degli spazi 0–5 in px: 0, 4, 8, 16, 24, 48.
.modal, .dropdown<dialog class="kit-dialog">, .kit-dropdownIl dialog è l'elemento nativo del browser.
Tema con data-bs-themedata-theme su <html>Automatico di base, forzabile a chiaro o scuro.
Breakpoint xxl—Non presente: si aggiunge in tools/gen-grid.py.
