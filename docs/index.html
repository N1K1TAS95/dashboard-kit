Snippet per VS Code

Digita il prefisso in un file .html e premi Tab: si espande il markup del componente, con i campi da compilare.

Installazione: copia vscode/dashboard-kit.code-snippets nella cartella .vscode/ del tuo progetto (solo quel progetto), oppure usa Preferences: Configure Snippets → New Global Snippets file e incolla il contenuto (tutti i progetti).

Personalizzazione

Tutto passa dai token CSS. Per cambiare il colore di accento o la densità basta sovrascriverli:

:root {
    --kit-accent: light-dark(#0f766e, #5eead4);
    --kit-accent-soft: light-dark(#e6f6f4, #12312e);
    --kit-rad: 8px;     /* angoli meno arrotondati */
    --kit-row: 5px;     /* tabelle più compatte */
}

Titolo del dialog

Si chiude con Esc, con un click sullo sfondo o con il bottone.
