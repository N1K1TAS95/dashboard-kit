JavaScript

Il JavaScript è opzionale. Senza kit.js tutto lo stile funziona; serve solo per le parti che si muovono: tema, tab, select, menu, dialog e toast.

Principi

  • Nessuna dipendenza e nessuna build: un solo file, dist/kit.js.
  • Si attiva con attributi data-kit-*, senza scrivere codice.
  • Non usa innerHTML, eval né script inline: funziona con script-src 'self'.
  • I gestori sono delegati al documento, quindi valgono anche per l'HTML aggiunto dopo il caricamento.

Attributi

AttributoDoveCosa fa
data-kit-theme-set="auto|light|dark"un bottone o una voce di menuImposta il tema e lo ricorda.
data-kit-fs-set="md|lg|xl"un bottone o una voce di menuImposta la dimensione del testo di tutta la pagina e la ricorda.
data-kit-fs-step="1|-1"un bottoneIngrandisce (1) o rimpicciolisce (-1) il testo di un passo; si disattiva agli estremi.
data-kit-resetun bottoneRipristina tema, dimensione del testo e larghezza (vedi pannello delle impostazioni).
data-kit-layout-set="boxed|fluid"un bottoneSceglie contenuto centrato o a tutta larghezza e lo ricorda.
data-kit-layout-toggleun bottoneAlterna le due larghezze.
data-kit-nav="#id"il bottone di una navbarApre o chiude il menu a scomparsa indicato (.kit-navbar-menu); Esc o un click fuori lo chiudono.
data-kit-toggle="#id"un bottoneApre o chiude il .kit-pop indicato.
data-kit-select.kit-selectTrasforma l'elenco di opzioni in un select. Su un <select> nativo lo sostituisce con il menu del kit (dettagli).
data-kit-tabs.kit-tabsAttiva le tab; ogni .kit-tab ha data-kit-panel="#id".
data-kit-open="#id"un bottoneApre il <dialog> indicato.
data-kit-confirm="Domanda?"un bottone, un link o un <form>Prima chiede conferma in un dialog; l'azione prosegue solo se l'utente conferma. Vedi Chiedere conferma.
data-kit-sort, data-kit-filter="#id", data-kit-page="N"<table>; il campo di ricerca; <table>Ordinamento dalle intestazioni, filtro di testo e paginazione (dettagli).
data-kit-datepicker, data-kit-timepicker, data-kit-daterange<input type="date|datetime-local|time">; un contenitore con due campi dataCalendario, selettore dell'ora e intervallo di date, con valore ISO nel form (dettagli).
data-kit-validate, data-kit-password, data-kit-count="#id"un <form>; un bottone accanto a un campo password; un elemento di testoValidazione con messaggi e stati, mostra/nascondi password, contatore dei caratteri (dettagli).
data-kit-closedentro un <dialog>Chiude il dialog.

API

Kit.toast("Salvato!");          // messaggio temporaneo; opzioni: type, title, duration, position, action, progress (vedi Dialog e menu)
Kit.toast.clear();              // chiude tutti i toast
await Kit.confirm("Eliminare?", { danger: true });   // dialog di conferma → true / false (opzioni: text, confirm, cancel, danger, type)
Kit.undo("Eliminata", { onUndo, onCommit });         // azione subito, con toast "Annulla"; onCommit se non si annulla
Kit.theme.get();                // "auto" | "light" | "dark"
Kit.theme.set("dark");          // imposta e salva il tema
Kit.fontSize.get();             // "sm" | "md" | "lg" | "xl"
Kit.fontSize.set("lg");         // imposta e salva la dimensione del testo
Kit.fontSize.step(1);           // un passo più grande (-1: più piccolo)
Kit.reset();                    // ripristina tema, testo e larghezza
Kit.layout.get();               // "boxed" | "fluid"
Kit.layout.set("fluid");        // contenuto a tutta larghezza (si ricorda)
Kit.layout.toggle();            // alterna
Kit.table("#tabella", { sort: true, size: 10 });   // ordine, filtro e pagine di una tabella (vedi Tabelle); Kit.paginate("#tabella", 10) per le sole pagine
Kit.datepicker("#scadenza");    // calendario su un campo data, data e ora o ora (vedi Date e orari); Kit.daterange("#periodo") per l'intervallo
Kit.validate("#form");           // controlla un form (true/false) e ne segna i campi; Kit.validate.reset(form) toglie stati e messaggi
Kit.date.parse("5/3/26");       // "2026-03-05" (Kit.date.format, Kit.date.today)
Kit.init(elemento);             // rilegge select e tab di un'area aggiunta dopo il caricamento

Eventi

Sono CustomEvent che salgono nel DOM: si ascoltano sul documento o sull'elemento.

EventoSudetail
kit:change.kit-select{ value }: il data-value scelto (per un select nativo anche label)
kit:sort, kit:filter, kit:page<table>{ column, direction }, { query, count }, { page, pages, size, total }
kit:changecampo data, ora o intervallo{ value, display } (ISO e testo del campo) oppure { from, to }
kit:invalid<form data-kit-validate>{ fields }: i campi non validi al momento dell'invio
kit:tab.kit-tabs{ tab }: l'elemento della tab attivata
kit:theme<html>il tema impostato
kit:fs<html>la dimensione del testo impostata (sm, md, lg o xl)
kit:reset<html>le impostazioni sono state ripristinate
kit:layout<html>la larghezza impostata (boxed o fluid)
 
document.addEventListener("kit:change", (e) => {
  console.log("Scelto:", e.detail.value);
});

Tastiera

  • Menu e select aperti: frecce su/giù per scorrere le voci, Invio o spazio per scegliere, Esc per chiudere (il focus torna al bottone).
  • Tab: frecce sinistra/destra passano alla tab vicina.
  • Dialog: Esc lo chiude (comportamento nativo); anche un click sullo sfondo.
