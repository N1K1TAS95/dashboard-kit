Lista

Voci impilate nello stesso riquadro, come tante card unite: kit-list sul contenitore, kit-list-item su ogni voce. Il contenitore può essere <ul>, <ol> o <div>; le voci <li>, <a>, <button> o <div>. Un badge o un'icona dentro la voce si allineano da soli; kit-list-main raccoglie titolo e descrizione e occupa lo spazio libero.

Snippet di codice

Un blocco di codice colorato come in un editor: tag, attributi, stringhe, parole chiave, funzioni e commenti. Si scrive un normale <pre class="kit-code"> e con data-kit-code (con kit.js) il codice si colora da solo. Il valore è la lingua: html (anche con <script> e <style> dentro), js o css; senza, kit.js la indovina. Il testo va scritto con le entità (&lt; al posto di <), come in ogni pagina HTML. Senza kit.js il blocco resta leggibile, solo senza colori.

<button class="kit-btn kit-btn-primary" data-kit-open="#nuovo">
  <svg class="kit-icon"><use href="#i-plus"/></svg> Nuova fattura
</button>
// ricarica i documenti e mostra l'esito
const n = await caricaDocumenti({ anno: 2026, max: 50 });
Kit.toast(n + " documenti", { type: "success" });
.fattura:hover { background: var(--kit-hover); }
@media (max-width: 760px) { .fattura { padding: 8px; } }

Bottone «Copia»

Con data-kit-code-copy il blocco si mette in un kit-snippet e compare il bottone «Copia» (al passaggio del mouse, sempre visibile sul telefono). Il valore dell'attributo è l'etichetta; data-kit-code-copied è quella che appare dopo la copia. Quando il testo è copiato parte l'evento kit:copy con { text }.

Da JavaScript

Kit.code(pre, { lang, text, copy }) colora un blocco e restituisce { set(testo, lingua), text() }, utile quando il codice cambia (un esempio generato, un'anteprima). Kit.highlight(testo, lingua) restituisce invece un frammento di DOM già colorato, da inserire dove vuoi. Entrambi costruiscono solo nodi di testo e <span>, mai HTML: il codice mostrato non viene eseguito, qualunque cosa contenga. Oltre i 100.000 caratteri il testo resta senza colori, così un testo enorme non rallenta la pagina; una lingua sconosciuta viene indovinata.

```js const blocco = Kit.code("#esempio", { lang: "js", copy: true }); blocco.set("Kit.toast('Salvato!');"); // cambia il codice mostrato elemento.append(Kit.highlight("ciao", "html")); ```

I colori sono i token --kit-hl-tag, -attr, -str, -kw, -fn, -num e -com (vedi Temi e token), e cambiano da soli tra tema chiaro e scuro.
