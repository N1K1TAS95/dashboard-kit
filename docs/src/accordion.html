Accordion

Un elenco di sezioni che si aprono e si chiudono, costruito sull'elemento nativo <details>: funziona anche senza JavaScript, si usa da tastiera (Invio e Spazio sul titolo) ed è già leggibile dagli screen reader. Il contenitore è kit-accordion, ogni voce è un <details> figlio diretto con un <summary> come titolo e il contenuto dentro kit-accordion-body. open sul <details> lo apre di partenza. Dove il browser lo supporta l'apertura è animata (con «riduci animazioni» no).

Come si emette una fattura?

Dal menu Fatture si sceglie «Nuova», si compilano cliente e righe e si salva: il numero viene assegnato in automatico.

Posso modificarla dopo l'invio?

No: una fattura inviata si corregge con una nota di credito e una nuova fattura.

Dove trovo le fatture scartate?

Nell'elenco, con il filtro «Scartata». Il motivo dello scarto è nel dettaglio.

Uno solo aperto

data-kit-accordion="single" (richiede kit.js) chiude le altre voci quando se ne apre una; se più voci partono aperte resta aperta solo la prima. Senza JavaScript lo stesso effetto si ottiene con lo stesso name="…" su tutti i <details>, che i browser recenti rispettano da soli. Un accordion dentro la voce di un altro è indipendente.

Con un'etichetta e dentro una card

kit-accordion-meta dentro il <summary> mette a destra un conteggio o un badge, prima della freccia. kit-accordion-flush toglie il riquadro e le ombre, per l'accordion dentro una card o un pannello.

JavaScript

Kit.accordion(elemento, { single }) fa lo stesso da codice e restituisce { open(x), close(x), toggle(x), openAll(), closeAll(), items() }, dove x è la posizione (da 0) o il <details>. Ogni apertura e chiusura lancia kit:accordion con { item, index, open }. In stampa tutte le voci si mostrano aperte.

const acc = Kit.accordion("#faq", { single: true });

acc.open(2);        // apre la terza voce (e chiude le altre)
acc.closeAll();

document.querySelector("#faq").addEventListener("kit:accordion", (e) => {
  console.log(e.detail.index, e.detail.open);
});
