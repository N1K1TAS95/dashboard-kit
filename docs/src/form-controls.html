Select personalizzato

Un menu a tendina con voci, gruppi e una seconda riga di testo. Richiede kit.js. Al cambio parte l'evento kit:change (vedi JavaScript). Per un <select> normale basta class="kit-input".

Da un select nativo

Se i dati sono già in un <select> (anche generato dal server, dentro un form, con required) basta aggiungergli data-kit-select: il kit lo nasconde e gli mette accanto bottone e menu. Il <select> resta la fonte dei dati: value, l'invio del form e l'evento change funzionano come sempre (parte anche kit:change, con { value, label }). Si usano i <optgroup> per i gruppi; data-kit-hint su un'opzione aggiunge una seconda riga e data-kit-short un testo più breve per il bottone. Dalle 21 voci in su il menu ha un campo di ricerca (data-kit-search="8" cambia la soglia, data-kit-search="" lo mette sempre, data-kit-search="off" mai). Le opzioni e disabled si possono cambiare dopo: il kit se ne accorge.

Valore: TD01

Da JavaScript: Kit.select(el, { search, empty, placeholder }) fa lo stesso per un select aggiunto in seguito (Kit.init(radice) lo fa per tutti quelli dentro radice) e restituisce { sync(), open(), close() }. Se si cambia select.value da codice, si chiama sync() per aggiornare il bottone (change lanciato a mano lo fa già).

Campo file

Un campo per scegliere uno o più file: bottone, nome del file scelto e «×» per rimuovere. Richiede kit.js (senza, resta il campo nativo del browser). Si scrive un normale <input type="file"> dentro kit-file con data-kit-file; accept e multiple funzionano come sempre. Il kit controlla il tipo e, con data-kit-file-max (in MB), la dimensione, e mostra l'errore sotto il campo. I file restano anche nel campo del form, quindi l'invio normale funziona.

Fatture
Accetta XML e P7M, fino a 2 MB ciascuno.

Zona di rilascio

La stessa cosa in grande: un'area in cui si trascinano i file, oppure ci si clicca per scegliere. Il campo nativo copre tutta l'area, quindi la tastiera funziona (Tab e Invio). Con data-kit-file-dir (o webkitdirectory sul campo) accetta anche le cartelle, che vengono lette per intero: i file di un altro tipo si ignorano in silenzio, mentre un file di un altro tipo scelto direttamente dà errore. Con data-kit-file-page si può rilasciare in qualsiasi punto della pagina: mentre si trascina compare un velo con il testo indicato.

Trascina qui le fatture o una cartella oppure scegli dal computer XML o P7M, fino a 2 MB ciascuno

Nessun file.

Quando i file cambiano l'elemento riceve kit:files con { files, items, rejected }: files sono i File accettati, items li accompagna con il percorso ({ file, path }, utile per le cartelle) e rejected elenca quelli scartati con il motivo (type, size, count, folder). Si può anche passare onFiles a Kit.file(elemento, opzioni).

Combobox

Un campo di testo con un elenco di suggerimenti che si restringe mentre si scrive. A differenza del select si può anche scrivere un valore che non è nell'elenco. Richiede kit.js. Frecce su e giù scorrono le voci, Invio sceglie quella evidenziata (all'apertura è la prima), Esc chiude, Tab esce. La scelta scrive il valore nel campo e fa partire input e kit:change ({ value, label }).

Le voci si scrivono nell'HTML, come kit-opt dentro un kit-pop; il bottone con la freccia si aggiunge da solo.

Per un elenco lungo o calcolato dai dati si usa Kit.combo. items è un array (o una funzione che lo restituisce) di stringhe oppure di oggetti { value, label, hint }. Il filtro cerca in etichetta, nota e valore; se ci sono più di max voci ne mostra max e invita a scrivere ancora.
