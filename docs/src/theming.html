Tema chiaro e scuro

I colori sono scritti una volta sola con light-dark(chiaro, scuro). Di base il tema segue il sistema; per forzarlo imposta data-theme su <html>. Con kit.js bastano i bottoni con data-kit-theme-set (la scelta viene ricordata); il menu "Tema" in alto a destra di queste pagine è fatto così.

Token di layout

Regolano il respiro dell'interfaccia. Sotto i 760px --kit-sp scende da 16 a 8px.

Token di colore

Ogni colore ha il valore per il tema chiaro e per quello scuro. Le classi del kit usano sempre i token, mai colori fissi: cambiando un token cambia dappertutto.

Personalizzare

Sovrascrivi i token in :root dopo aver caricato kit.css:

```css :root { --kit-accent: light-dark(#0f766e, #5eead4); --kit-accent-soft: light-dark(#e6f6f4, #12312e); --kit-rad: 8px; /* angoli meno arrotondati */ --kit-row: 5px; /* tabelle più compatte */ --kit-ctl: 36px; /* bottoni e campi più bassi */ } ```
