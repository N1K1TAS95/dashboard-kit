Accordion

A list of sections that open and close, built on the native <details> element: it works without JavaScript, is used from the keyboard (Enter and Space on the title) and is already readable by screen readers. The container is kit-accordion, each item is a direct-child <details> with a <summary> as the title and the content inside kit-accordion-body. open on the <details> opens it initially. Where the browser supports it the opening is animated (not with "reduce motion").

How do I issue an invoice?

From the Invoices menu choose "New", fill in the customer and lines and save: the number is assigned automatically.

Can I edit it after sending?

No: a sent invoice is corrected with a credit note and a new invoice.

Where do I find rejected invoices?

In the list, with the "Discarded" filter. The reason for the rejection is in the detail.

Only one open

data-kit-accordion="single" (requires kit.js) closes the other items when one is opened; if several items start open only the first stays open. Without JavaScript the same effect is achieved with the same name="…" on all the <details>, which recent browsers honor by themselves. An accordion inside another's item is independent.

With a label and inside a card

kit-accordion-meta inside the <summary> puts a count or a badge on the right, before the arrow. kit-accordion-flush removes the box and shadows, for an accordion inside a card or a panel.

JavaScript

Kit.accordion(element, { single }) does the same from code and returns { open(x), close(x), toggle(x), openAll(), closeAll(), items() }, where x is the position (from 0) or the <details>. Every opening and closing fires kit:accordion with { item, index, open }. When printing all items are shown open.

const acc = Kit.accordion("#faq", { single: true });

acc.open(2);        // opens the third item (and closes the others)
acc.closeAll();

document.querySelector("#faq").addEventListener("kit:accordion", (e) => {
  console.log(e.detail.index, e.detail.open);
});
