Breadcrumb

It shows where you are in the site hierarchy and lets you go back up. It is CSS only: a <nav class="kit-breadcrumb"> with an <ol>, one <li> per level and aria-current="page" on the last one, which is the current page and not a link. The separator is drawn by CSS, so the screen reader reads only the names. The <nav> needs an aria-label (for example "Breadcrumb") to tell it apart from the others.

Separator and icon

By default the separator is a small arrow; kit-breadcrumb-slash uses the slash. An icon (kit-icon) before an item's text aligns by itself: usually the house for the first one.

Long paths on narrow screens

With kit-breadcrumb-collapse, below 576px only the first and last items remain, on a single line (the last one is shortened with an ellipsis if it does not fit). In place of the hidden items a kit-breadcrumb-more item with "…" appears, which you write after the first one and which is only visible on those screens; it is aria-hidden because the hidden items are not read. Narrow the window to see it.

With a kit-header or at the top of a page the breadcrumb sits well above the title, with a margin-bottom of one or two spacing units. If the server computes the levels (Django, for example) a loop is enough that writes an <li> with a link for each ancestor and the last one with aria-current.
