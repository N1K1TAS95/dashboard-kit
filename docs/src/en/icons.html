Usage

Icons are strokes on a 24×24 grid that take the text color (currentColor). They are used with <svg class="kit-icon"> and <use>; the name is the symbol's id, preceded by i-.

An icon on its own, without text, needs an aria-label on the button that contains it. If it is only decorative, add aria-hidden="true" to the <svg>.

Installation

Sprites cannot be loaded from another domain with a <use> that points to an SVG file: that is why the kit inserts them with a small script. Add it before closing </body>:

If you prefer not to use JavaScript, copy the content of dist/kit-icons.svg to the start of the <body> (this is what this documentation does) or keep only the icons you need in the sprite.

If you already have your own sprite with the same ids, the first one the browser finds wins: there is no conflict, but check that the icons are the ones you expect.

Size and color

The icon is 18px and takes the text color. To change it use width/height and color.

List

All the available icons, with the name to use after #i-.

Adding an icon

Icons are defined in tools/icons.py (name → SVG strokes). Add a line, then run python3 tools/icons.py: it regenerates dist/kit-icons.svg and dist/kit-icons.js. Draw them on 24×24, stroke only, with no fixed colors.
