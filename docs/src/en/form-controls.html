Custom select

A dropdown menu with items, groups and a second line of text. It needs kit.js. On change the kit:change event fires (see JavaScript). For a plain <select> just use class="kit-input".

The option with is-on is the initial one. kit-pop-right on the panel aligns it to the right of the button.

From a native select

If the data is already in a <select> (even one generated by the server, inside a form, with required) just add data-kit-select to it: the kit hides it and puts a button and menu next to it. The <select> stays the source of the data: value, form submission and the change event work as usual (kit:change also fires, with { value, label }). Use <optgroup> for groups; data-kit-hint on an option adds a second line and data-kit-short a shorter text for the button. From 21 items up the menu has a search field (data-kit-search="8" changes the threshold, data-kit-search="" always shows it, data-kit-search="off" never). Options and disabled can be changed later: the kit notices.

Value: TD01

From JavaScript: Kit.select(el, { search, empty, placeholder }) does the same for a select added later (Kit.init(root) does it for all those inside root) and returns { sync(), open(), close() }. If you change select.value from code, call sync() to update the button (a change fired by hand already does).

File field

A field to choose one or more files: a button, the name of the chosen file and an "×" to remove it. It needs kit.js (without it, the browser's native field stays). Write a normal <input type="file"> inside kit-file with data-kit-file; accept and multiple work as usual. The kit checks the type and, with data-kit-file-max (in MB), the size, and shows the error below the field. The files also stay in the form's field, so normal submission works.

Invoices
Accepts XML and P7M, up to 2 MB each.

Drop zone

The same thing, bigger: an area where you drag files, or click to choose. The native field covers the whole area, so the keyboard works (Tab and Enter). With data-kit-file-dir (or webkitdirectory on the field) it also accepts folders, which are read in full: files of another type are silently ignored, while a file of another type chosen directly gives an error. With data-kit-file-page you can drop anywhere on the page: while dragging, a veil appears with the given text.

Combobox

A text field with a list of suggestions that narrows as you type. Unlike the select you can also type a value that is not in the list. It needs kit.js. Up and down arrows move through the items, Enter chooses the highlighted one (on opening it is the first), Esc closes, Tab leaves. Choosing writes the value into the field and fires input and kit:change ({ value, label }).

Items are written in the HTML, as kit-opt inside a kit-pop; the button with the arrow is added automatically.
