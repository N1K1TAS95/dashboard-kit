Base text

The kit uses the Inter font at 1rem with line height --kit-lh (1.5). 1rem is the base size --kit-fs, which grows with the screen and can be chosen by the user (see Font and text size): all the sizes below are in rem or em, so they follow it. Zeros are slashed, so they are not confused with the letter "o".

Headings

The <h1>…<h6> elements already have the kit's style. The kit-h1…kit-h6 classes give the same look to another element (a <p>, a <div>) without changing the document structure. A <small> inside the heading becomes a gray secondary text.

Inline text

You can highlight a part (<mark>), delete (<del>), insert (<ins>), underline (<u>), make bold or italic, and write in smaller type (<small>).

Abbreviations show their meaning on mouse hover: VAT, and in small caps with kit-initialism: html.

For a key use Ctrl + K; for code kit-card.

Long texts

An article, a guide or some notes read better with shorter lines and more space between lines. kit-prose limits the width to --kit-measure (65 characters), brings the line height to 1.7 and spaces paragraphs, headings and lists regularly, without you having to put classes on the single elements. To limit only the width of a block there is kit-measure.

How a long text is read

When a line goes past about seventy characters the eye struggles to return to the start of the next line. This is why long texts should not take up the whole width of a large screen.

Line height matters too: lines that are too close blur together, lines too far apart read as separate paragraphs.

Some tips

  • Keep lines under 65–75 characters.
  • Use a line height between 1.5 and 1.7.
  • Give headings more space above than below.
