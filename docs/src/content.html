Accordion

Un elenco di sezioni che si aprono e si chiudono, costruito sull'elemento nativo <details>: funziona anche senza JavaScript, si usa da tastiera (Invio e Spazio sul titolo) ed è già leggibile dagli screen reader. Il contenitore è kit-accordion, ogni voce è un <details> figlio diretto con un <summary> come titolo e il contenuto dentro kit-accordion-body. open sul <details> lo apre di partenza. Dove il browser lo supporta l'apertura è animata (con «riduci animazioni» no).

Come si emette una fattura?

Dal menu Fatture si sceglie «Nuova», si compilano cliente e righe e si salva: il numero viene assegnato in automatico.

Posso modificarla dopo l'invio?

No: una fattura inviata si corregge con una nota di credito e una nuova fattura.

Dove trovo le fatture scartate?

Nell'elenco, con il filtro «Scartata». Il motivo dello scarto è nel dettaglio.

Uno solo aperto

data-kit-accordion="single" (richiede kit.js) chiude le altre voci quando se ne apre una; se più voci partono aperte resta aperta solo la prima. Senza JavaScript lo stesso effetto si ottiene con lo stesso name="…" su tutti i <details>, che i browser recenti rispettano da soli. Un accordion dentro la voce di un altro è indipendente.

JavaScript

Kit.accordion(elemento, { single }) fa lo stesso da codice e restituisce { open(x), close(x), toggle(x), openAll(), closeAll(), items() }, dove x è la posizione (da 0) o il <details>. Ogni apertura e chiusura lancia kit:accordion con { item, index, open }. In stampa tutte le voci si mostrano aperte.

const acc = Kit.accordion("#faq", { single: true });

acc.open(2);        // apre la terza voce (e chiude le altre)
acc.closeAll();

document.querySelector("#faq").addEventListener("kit:accordion", (e) => {
  console.log(e.detail.index, e.detail.open);
});

Snippet di codice

Un blocco di codice colorato come in un editor: tag, attributi, stringhe, parole chiave, funzioni e commenti. Si scrive un normale <pre class="kit-code"> e con data-kit-code (con kit.js) il codice si colora da solo. Il valore è la lingua: html (anche con <script> e <style> dentro), js o css; senza, kit.js la indovina. Il testo va scritto con le entità (&lt; al posto di <), come in ogni pagina HTML. Senza kit.js il blocco resta leggibile, solo senza colori.

<button class="kit-btn kit-btn-primary" data-kit-open="#nuovo">
  <svg class="kit-icon"><use href="#i-plus"/></svg> Nuova fattura
</button>
// ricarica i documenti e mostra l'esito
const n = await caricaDocumenti({ anno: 2026, max: 50 });
Kit.toast(n + " documenti", { type: "success" });
.fattura:hover { background: var(--kit-hover); }
@media (max-width: 760px) { .fattura { padding: 8px; } }

Bottone «Copia»

Con data-kit-code-copy il blocco si mette in un kit-snippet e compare il bottone «Copia» (al passaggio del mouse, sempre visibile sul telefono). Il valore dell'attributo è l'etichetta; data-kit-code-copied è quella che appare dopo la copia. Quando il testo è copiato parte l'evento kit:copy con { text }.

Da JavaScript

Kit.code(pre, { lang, text, copy }) colora un blocco e restituisce { set(testo, lingua), text() }, utile quando il codice cambia (un esempio generato, un'anteprima). Kit.highlight(testo, lingua) restituisce invece un frammento di DOM già colorato, da inserire dove vuoi. Entrambi costruiscono solo nodi di testo e <span>, mai HTML: il codice mostrato non viene eseguito, qualunque cosa contenga. Oltre i 100.000 caratteri il testo resta senza colori, così un testo enorme non rallenta la pagina; una lingua sconosciuta viene indovinata.

```js const blocco = Kit.code("#esempio", { lang: "js", copy: true }); blocco.set("Kit.toast('Salvato!');"); // cambia il codice mostrato elemento.append(Kit.highlight("ciao", "html")); ```

I colori sono i token --kit-hl-tag, -attr, -str, -kw, -fn, -num e -com (vedi Temi e token), e cambiano da soli tra tema chiaro e scuro.

Legenda dei grafici

I colori delle serie sono i token --kit-c1 e --kit-c2, che cambiano da soli tra tema chiaro e scuro. Nei grafici SVG usali con fill: var(--kit-c1) (vedi la dashboard di esempio).
