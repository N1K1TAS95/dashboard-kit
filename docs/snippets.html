Snippet VS Code

Digita il prefisso e premi Tab: l'editor scrive il markup del componente, con i campi da compilare.

Installazione

  • Solo un progetto: copia vscode/dashboard-kit.code-snippets nella cartella .vscode/ del progetto.
  • Tutti i progetti: in VS Code apri Preferences: Configure Snippets → New Global Snippets file e incolla il contenuto del file.

Poi, in un file .html, scrivi per esempio kit-card e premi Tab. Con kit-page ottieni una pagina intera; con kit-dash lo schema di una dashboard (KPI, grafico con laterale, tabella).
